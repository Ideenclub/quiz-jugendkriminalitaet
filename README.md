# Recht oder Unrecht? – Einstiegsquiz Jugendkriminalität

Interaktives Quiz für die erste Stunde der Unterrichtsreihe „Jugendkriminalität“ (Gesellschaftslehre, Klasse 7, Gesamtschule NRW). Für iPads optimiert, läuft aber auch auf Smartphones und am Whiteboard.

## Inhalt
12 Fragen: Grundbegriffe (Straftat, Strafmündigkeit, Jugendstrafrecht), eine Meinungsfrage, Alltagssituationen (Graffiti, Schultoiletten, Schwarzfahren, Fotos im Klassenchat, Weiterleiten, Mutprobe) und zwei Schätzfragen. Nach jeder Antwort folgt eine kurze Erklärung mit Rechtsgrundlage und einer Frage, die neugierig macht. Am Ende stehen Punktzahl und eine offene Frage für das Unterrichtsgespräch.

## Technik
- Eine einzige Datei: `index.html`, keine externen Ressourcen
- Keine Namenseingabe, keine Cookies, kein localStorage, keine Datenübertragung
- GitHub Pages: Settings → Pages → Branch `main`, Ordner `/ (root)`

## Quellen
StGB, JGG, BGB § 828, KUG §§ 22/33, SchulG NRW § 53, Polizeiliche Kriminalstatistik 2025 (BKA). Die vollständige Liste steht im Quiz auf der Ergebnisseite.
